Projet Python · Epitech

Hangman : construire un jeu de A à Z

Un projet qui m'a accompagné dans mes premiers pas en programmation, en évoluant progressivement d'un jeu en terminal vers une application graphique.

Contexte
Formation Epitech
Langage
Python
Outils
Argparse · Pygame · Git

Le point de départ

Le jeu du pendu paraît simple, mais il oblige à maîtriser les bases : boucles, conditions, gestion des entrées et organisation du code. C'était le terrain idéal pour apprendre, puis enrichir le programme étape par étape.

Les étapes du projet

  1. La logique du jeu

    Choix du mot, lettres proposées, essais restants, conditions de victoire et de défaite.

  2. Les entrées utilisateur

    Lire et vérifier ce que saisit le joueur pour que le jeu reste fiable.

  3. Une liste de mots externe

    Charger les mots depuis un fichier plutôt que de les écrire dans le code.

  4. Des options au lancement

    Avec Argparse, plusieurs niveaux de personnalisation de la partie depuis la ligne de commande.

  5. La gestion des erreurs

    Fichier introuvable, saisie invalide : le programme réagit proprement au lieu de s'arrêter.

  6. Les meilleurs scores

    Un système pour enregistrer et afficher les meilleurs résultats.

  7. L'interface graphique

    Le passage du terminal à une vraie fenêtre de jeu réalisée avec Pygame.

Ce que j'en retiens

Ce projet m'a appris à faire évoluer un programme pas à pas, en ajoutant des fonctionnalités sans casser ce qui fonctionnait déjà. Partir d'une base simple, la livrer, puis l'améliorer : c'est aussi la démarche que je veux appliquer dans la conduite de projets numériques.
