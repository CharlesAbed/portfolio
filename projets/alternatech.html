AlternaTech — plateforme de recherche d'emploi

Un job board consacré aux offres tech en France, développé en binôme : une interface web, une API PHP et une base de données relationnelle qui relient candidats, recruteurs et administrateurs.

Contexte
Projet en binôme
Stack
PHP · MySQL · HTML · CSS · JavaScript
Outils
PDO · Git · Node.js (tests)

Le projet

AlternaTech permet de consulter des offres d'emploi, d'y postuler et de les gérer côté recruteur. Le défi était de faire travailler ensemble plusieurs profils d'utilisateurs, chacun avec ses droits, autour d'une même base de données.

Architecture

  1. Interface en HTML, CSS et JavaScript natifs

    Sans framework : les pages appellent l'API en JSON et affichent le détail d'une offre sans rechargement.

  2. API en PHP

    Un routeur PHP sans framework, des requêtes SQL préparées avec PDO, des sessions, une protection CSRF et des contrôles d'accès vérifiés côté serveur.

  3. Base de données MySQL

    Un schéma relationnel (comptes, profils, entreprises, catégories, annonces, candidatures…) avec des scripts d'installation et de migration.

Fonctionnalités implémentées

  1. Consultation des annonces

    Liste paginée avec filtres par mot-clé, lieu et catégorie, et détail de l'offre affiché à côté de la liste.

  2. Candidatures

    Un bouton « Postuler » sur chaque offre : formulaire pour les visiteurs, profil réutilisé pour les utilisateurs connectés, doublons bloqués en base.

  3. Comptes utilisateurs

    Inscription, connexion par e-mail et mot de passe, modification du profil et suivi de ses propres candidatures.

  4. Espace recruteur

    Publication, modification et suppression des annonces de ses entreprises, consultation des candidats et mise à jour du statut des candidatures.

  5. Administration

    Une page réservée aux administrateurs pour gérer toutes les tables, avec pagination et vérification des relations avant suppression.

  6. Interface bilingue

    Un sélecteur français / anglais qui s'appuie sur un dictionnaire commun au PHP et au JavaScript.

Ma contribution

Mon binôme a posé la structure du projet, la base de données, la liste publique des annonces et la connexion Google. De mon côté, j'ai développé la connexion par e-mail et mot de passe, la sécurisation des annonces par recruteur, le parcours de candidature, l'espace recruteur et les tests HTTP associés, puis j'ai participé à l'intégration finale.

Ce que j'en retiens

Travailler à deux sur le même code m'a appris à intégrer mon travail sans casser celui de l'autre, à m'appuyer sur des tests et à documenter les choix. Distinguer ce qui est réellement fait de ce qui reste à valider, c'est aussi une exigence du pilotage de projet.
